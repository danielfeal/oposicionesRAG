# Qué es oposicionesRAG
oposicionesRAG es un asistente conversacional para estudiantes de oposiciones basado en Retrieval Augmented Generation.

Esta aplicación se ha desarrollado como parte de mi TFM para el máster en Big Data, Data Science e Inteligencia Artifical de la Universidad Complutense de Madrid. 

Si cuentas con una clave de acceso, puedes acceder a la aplicación en [rag-oposiciones.duckdns.org](https://rag-oposiciones.duckdns.org).

El proyecto está disponible como código abierto bajo una licencia MIT. Cualquier contribución al proyecto es bienvenida.
